# carrinho-de-compras
Aplicação web de cadastro de produtos feita com Flask e Bootstrap 5. O usuário informa nome e preço em um formulário, vê os itens em uma tabela responsiva e acompanha o total do carrinho, calculado automaticamente a cada novo cadastro. Os dados ficam em memória, sem banco de dados. Ideal para estudo de Flask e Jinja2.
